# /oasis-add-telerik-ui

1. Find an existing OASIS component with the closest interaction and data shape.
2. Verify the installed Telerik UI for Blazor package version and available APIs.
3. Trace data source, API/service calls, DTOs, loading/error states, authorization, and disposal.
4. Reuse existing CSS/theme, localization, validation, and notification patterns.
5. Implement only the requested UI behavior; do not upgrade Telerik or redesign global components.
6. Consider empty/loading/error states, paging/filtering, accessibility, and request cancellation.
7. Build the affected project and test the relevant interaction where possible.
8. Report assumptions and any behavior not verified in a running browser.
