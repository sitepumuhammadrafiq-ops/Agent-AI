# Telerik UI playbook

1. Check package references and the installed Telerik version.
2. Search for the closest existing component in the repository.
3. Confirm component parameters, event callback types, templates, and binding behavior from installed-version documentation or local usage.
4. Preserve project theme, CSS, localization, validation, notification, and layout patterns.
5. For grids, inspect paging, sorting, filtering, server/client data mode, and empty/loading/error states.
6. For forms, inspect validation model, field names, server validation, and submission state.
7. For charts, inspect data shape, null/empty cases, legends, labels, and resize behavior.
8. Build the affected project and report browser verification separately.
